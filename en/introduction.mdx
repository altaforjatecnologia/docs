## What is Integrabot?

Integrabot is a customer service automation platform that combines **advanced Artificial Intelligence** with **WebChat** (embedded chat widget) and **Telegram** to transform how you communicate with your customers.

## Key Features

### 🤖 Customizable AI Assistant

- **Goal and Instructions**: Define the assistant's purpose and guidelines
- **Communication Style**: Formal, balanced or empathetic
- **Restrictions**: Establish business rules
- **Custom Tools**: Connect APIs and external systems

### 📚 Intelligent Knowledge Base

- Import website content automatically
- Upload documents (PDF, DOC, DOCX, TXT)
- Add text directly with the integrated editor
- Organize content by categories

### 💬 Conversation Management

- View all conversations in real time
- Human intervention when needed
- Full message history
- Transfer between AI and human agent

### 🔧 AI Tools

- Native system tools
- External API integration
- Automated actions
- Webhooks for integrations
