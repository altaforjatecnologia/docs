# Integrações

A IntegraBot conecta seu Assistente de IA a canais de comunicação para atender clientes diretamente onde eles estão.

Para acessar:

1. Selecione seu Assistente no Dashboard
2. Clique em "Integrações" no menu lateral
3. Visualize as integrações disponíveis e ativas

## Widget para Site

A forma mais simples de adicionar seu Assistente ao seu site: uma janela de chat flutuante.

### Como configurar

1. Acesse **Integrações** > **Widget**
2. Clique em **Configurar**
3. Personalize aparência (cores, posição, tamanho)
4. Copie o código de integração gerado
5. Cole o código no HTML do seu site antes da tag `</body>`

### Personalização

- **Cor de fundo**
- **Cor do texto**
- **Posição** (direita / esquerda)
- **Espaçamento das bordas**
- **Mensagem inicial**

## Iframe

Incorpore o Assistente diretamente em uma página específica do seu site.

### Como configurar

1. Acesse **Integrações** > **Iframe**
2. Defina largura e altura (px ou %)
3. Copie o código de integração
4. Cole no local desejado do HTML

## Telegram

Integre seu Assistente ao Telegram via bot.

### Como configurar

1. Acesse **Integrações** > **Telegram**
2. Clique em **Ativar integração**
3. Crie um bot no [@BotFather](https://t.me/BotFather) e copie o token
4. Cole o token na configuração da IntegraBot
5. Salve e teste enviando uma mensagem ao bot

## Gerenciamento de Integrações

### Ativação e Desativação

- **Ativar**: habilita a integração
- **Desativar**: pausa temporariamente
- **Remover**: desconecta completamente

### Monitoramento

- **Status de conexão**
- **Volume de mensagens**
- **Taxa de resposta**

Para detalhes de configuração de canais, consulte o [Guia de Criação de Canais](/essentials/criacao-canais).

## Requisitos

- **Widget e Iframe**: funcionam em qualquer site com acesso ao HTML
- **Telegram**: requer apenas um bot criado no @BotFather
