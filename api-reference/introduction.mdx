A API REST do Integrabot permite que você integre os recursos da plataforma diretamente no seu sistema. Crie leads a partir de formulários web, sincronize contatos com seu CRM ou automatize fluxos de trabalho com os agents de IA.

**Base URL:** `https://api.integrabot.ai`

**Content-Type:** `application/json`

## Autenticação

Todas as requisições precisam de uma API Key enviada no header `Authorization` como Bearer token. As API Keys do Integrabot começam com o prefixo `sk_`.

<Warning>
  Nunca exponha sua API Key no lado do cliente (JavaScript do navegador, apps mobile). Use sempre no backend ou em serviços seguros.
</Warning>

### Gerando uma API Key

1. Acesse o painel do Integrabot em [app.integrabot.ai](https://app.integrabot.ai)
2. Abra o modal de **Configurações** (ícone de engrenagem)
3. Navegue até a seção **API Keys**
4. Clique em **Gerar nova chave**
5. Copie a chave gerada (ela não será exibida novamente)

### Exemplo de requisição

```bash
curl -X GET https://api.integrabot.ai/v1/leads \
  -H "Authorization: Bearer sk_sua_api_key_aqui" \
  -H "Content-Type: application/json"
```

## Rate Limiting

A API tem um limite de **60 requisições por minuto** por API Key. Se você ultrapassar esse limite, receberá uma resposta `429 Too Many Requests` com o header `Retry-After` indicando quantos segundos aguardar.

## Respostas de Erro

Todas as respostas de erro seguem o formato:

```json
{
  "error": "Tipo do erro",
  "message": "Descrição detalhada do erro"
}
```

| Status | Significado |
|--------|-------------|
| 401 | API Key inválida ou ausente |
| 404 | Recurso não encontrado |
| 422 | Erro de validação nos dados enviados |
| 429 | Limite de requisições excedido |
| 500 | Erro interno do servidor |
