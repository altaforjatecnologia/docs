# Criação de Canais

Os canais são as interfaces através das quais seus clientes interagem com seu Assistente de IA. Este guia explica como criar e configurar os canais disponíveis.

## Tipos de Canais Disponíveis

### Widget Web

Chat embutido no seu site através de um snippet HTML.

- **Vantagens**: configuração simples, totalmente sob seu domínio
- **Como usar**: cole o snippet antes de `</body>` no HTML do site

### Iframe

Incorpore o Assistente em uma página específica do seu site.

- **Vantagens**: integração fixa em uma rota dedicada
- **Como usar**: defina dimensões e cole o iframe no HTML

### Telegram

Bot do Telegram para atender contatos diretamente no aplicativo.

- **Vantagens**: alcance amplo, infra gerenciada pelo Telegram
- **Como usar**: crie um bot no @BotFather e cole o token

## Como Criar um Novo Canal

### Passo 1: Acessar a seção Canais

1. Faça login na plataforma IntegraBot
2. Selecione o Assistente desejado
3. Clique em **Canais** no menu lateral
4. Clique em **Adicionar Canal**

### Passo 2: Selecionar o tipo de canal

1. Escolha entre **Widget Web**, **Iframe** ou **Telegram**
2. Clique em **Criar**

### Passo 3: Configurar o canal

#### Widget Web

1. Personalize cores, posição e mensagem inicial
2. Copie o snippet HTML
3. Cole no seu site antes de `</body>`
4. Acesse seu site para validar

#### Iframe

1. Defina largura e altura (px ou %)
2. Copie o código do iframe
3. Cole na página em que deseja exibir o Assistente

#### Telegram

1. Crie um bot pelo [@BotFather](https://t.me/BotFather)
2. Copie o token gerado
3. Cole o token na configuração do canal
4. Salve e teste enviando uma mensagem ao bot

### Desconexão e Remoção

- **Desconectar**: pausa o canal sem removê-lo
- **Reconectar**: reativa um canal pausado
- **Excluir**: remove o canal definitivamente

## Solução de Problemas

### Widget Web não aparece no site

1. Verifique se o snippet está antes de `</body>`
2. Confira o console do navegador (erros 4xx / 5xx)
3. Confirme se o domínio do site está autorizado no painel

### Bot do Telegram não responde

1. Verifique se o token está correto e ativo
2. Confirme que o webhook foi registrado (status "conectado" no painel)
3. Cheque os logs em **Conversas** para mensagens recebidas mas não processadas

## Melhores Práticas

1. **Teste antes de usar em produção**: configure e teste o canal antes de publicar
2. **Mantenha o token do Telegram seguro**: nunca compartilhe publicamente
3. **Monitore o desempenho**: revise periodicamente status e tempo de resposta
4. **Configure mensagens de fallback**: respostas para indisponibilidade do canal

- **Número de canais** por Assistente
- **Volume de mensagens** mensal
